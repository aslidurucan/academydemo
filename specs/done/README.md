# specs/done/

Tamamlanmış spec'lerin taşındığı klasör.

Bir spec'in [Definition of Done](../TEMPLATE.md#definition-of-done) listesindeki tüm kutular işaretlendiğinde ve PR merge edildiğinde, spec dosyası `specs/<no>-<ad>.md`'den buraya taşınır (`git mv`).

**Amaç:** `specs/` kök dizininin her zaman "şu an ne üzerinde çalışılıyor" listesi olarak kalması; tamamlananların da geçmiş referans/denetim izi olarak burada saklanması.
